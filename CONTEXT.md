# Research Repository - Technical & Contextual Overview

## Project Identity & Academic Context
* **Project**: Mentoring as a Catalyst: Structural Support Systems for MSW Students and Early-Career Practitioners
* **Repository**: `msw-mentorship-support-systems-research`
* **Published URL**: `https://mmonfils.github.io/msw-mentorship-support-systems-research/`

## Core Purpose
The Research Repository functions as the public-facing academic documentation portal, theoretical framework repository, accreditation reference, and facilitator setup hub for the mentorship research project.

## Single Source of Truth
* **Primary Academic Source**: `research/paper-core.md` is the sole authoritative text for all qualitative findings, empirical data, methodology, and citations. All theoretical summaries and accreditation mappings across the site defer to this file.

## Information Architecture & Navigation
* **SSG Engine**: Jekyll (`just-the-docs` theme).
* **Sidebar Structure**: Organizes content into explicit parent-child hierarchies using YAML front matter:
  * `research/`: Full academic paper draft and literature review.
  * `framework/`: Critical Pedagogy (Freirean problem-posing vs. banking model) and Systems Theory (Person-in-Environment & STEEPLE analysis).
  * `standards/`: CSWE 2022 EPAS Competencies (1, 2, 9) and NASW Code of Ethics alignment.
  * `appendices/`: IRB approvals, informed consent documentation, qualitative interview protocols, and thematic coding schemes.
  * `facilitator/`: Step-by-step instructions for Airtable Base configuration and live projector interface setup.
